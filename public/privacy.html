プライバシーポリシー

WearCast（以下「本アプリ」）は、個人が学習・ポートフォリオのために開発・運営しているアプリです。本アプリでの利用者の情報の取り扱いを、次のとおり定めます。

1. 集める情報

  • メールアドレスとパスワード（パスワードはそのまま保存せず、元に戻せない形に変換して保存します）
  • Googleでログインした場合の、Googleアカウントのメールアドレス
  • 利用者が登録した服の情報（名前・カテゴリー・色・写真など）
  • 天気を調べるために入力された都市名

端末の位置情報（GPS）は使いません。

2. 使う目的

  • ログインと、本人のメールアドレスであることの確認（確認メールの送信）
  • 登録した服の表示と、天気に合わせた服の提案

これ以外の目的には使わず、広告や宣伝のメールも送りません。

3. 外部のサービス

本アプリは次のサービスを使っており、必要な範囲で情報がそれぞれのサービスに送られます。

  • Google（Googleでのログイン、確認メールの送信）
  • Render（アプリの公開）、TiDB Cloud（データの保存）、Cloudinary（服の写真の保存）
  • Photon・Nominatim（都市名から場所を調べる）、MET Norway（天気予報）

これ以外の第三者に、利用者の情報を売ったり渡したりすることはありません（法令にもとづく場合を除きます）。

4. Googleから受け取る情報

Googleでのログインでは、Googleアカウントのメールアドレスだけを受け取り、ログインのためだけに使います。本アプリがGoogleのAPIから受け取った情報の使い方は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

5. Cookie

ログインした状態を保つためだけにCookieを使います。広告や利用状況の分析のためのCookieは使いません。

6. 情報の削除

登録した服は、アプリの中でいつでも削除できます。アカウントごと削除したい場合は、下のお問い合わせ先までご連絡ください。

7. お問い合わせ

GitHubのIssueからご連絡ください。

8. 変更

このポリシーを変更する場合は、このページでお知らせします。
